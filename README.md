# Oferta ML — página de presentación

Página estática para describir la extensión Oferta ML. No requiere frameworks, dependencias ni un servidor propio.

## Publicación con GitHub Pages

1. Abre el repositorio **iunsteve/ofertaML**.
2. Entra en **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/(root)`.
5. Guarda. GitHub Pages publicará la página en:

   https://iunsteve.github.io/ofertaML/

La publicación puede tardar unos minutos en estar disponible.

## Privacidad

La extensión realiza las búsquedas y consultas necesarias directamente contra los servicios de Mercado Libre. No se debe afirmar que ningún dato sale del navegador: los términos o identificadores de producto, el token de autorización y, cuando corresponda, la ciudad de destino se transmiten a Mercado Libre para prestar el servicio.
